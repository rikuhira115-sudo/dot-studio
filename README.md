# DOT STUDIO

無料で使える、ブラウザ完結型のドット絵エディターです。外部APIやサーバー処理は使わず、画像の読み込み・変換・描画は端末内で行います。

## 使い方

1. GitHub Pages を有効にすると、ブラウザで利用できます。
2. **画像を開く** から PNG / JPEG / WebP を選び、右パネルでピクセルの細かさ・色数・明るさ・コントラストを調整します。
3. **ドット絵に変換** を押すと、変換結果がキャンバスに読み込まれます。そのままペンなどで編集できます。
4. **PNGを書き出す** で透明部分を保ったPNGとして保存できます。
5. プロジェクト保存では、後から編集を再開できるJSON形式で作業データを保存できます。

## 実装済み

- 16 / 32 / 64 / 128 px のキャンバスプリセットとカスタムサイズ
- ペン、消しゴム、塗りつぶし、スポイト、直線、四角形
- 画像読み込みとピクセル化・色数削減・明るさ・コントラスト調整
- 色パレット、透明背景表示、ピクセルグリッド、ズーム
- Undo / Redo、PNG書き出し、JSONプロジェクト保存・読み込み
- ブラウザ内の自動保存、スマートフォン向けレスポンシブ表示

## 公開（GitHub Pages）

1. リポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の **Deploy from a branch** を選択します。
3. Branch を **main**、フォルダを **/(root)** にして Save を押します。
4. 数分後、表示された Pages URL からアクセスできます。

## 注意

自動保存は同じブラウザ・同じ端末内に保存されます。ブラウザのサイトデータを削除すると消えるため、重要な作業はJSONプロジェクトも保存してください。
